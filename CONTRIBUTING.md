# Contributing to VASH

1. **Propose a Change:** Open an issue describing the bug or feature.
2. **Submit a PR:** Ensure your PR references the issue.
3. **AvA Review:** The maintainer's pipeline will run the AvA (Agent vs Agent) review on your PR.

## Submitting a Catalog Asset
If you are submitting a skill, agent, or tool to the catalog (Law 3):
1. **Search Record:** Provide a record of what you searched for and what you found (to prove we are not reinventing the wheel).
2. **Licence Compatibility:** Ensure the licence is compatible with MIT, or, for an external tool that is only run and never copied or linked, its licence and run-only use are recorded in the catalog entry.
3. **Location:** Place the file in the appropriate `catalog/` subdirectory.

See [GOVERNANCE.md](GOVERNANCE.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for more details.
