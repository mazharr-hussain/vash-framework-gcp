# Security Policy

## Supported Versions
Only the latest `3.0.x` development and stable releases receive security updates. Older versions are not supported.

## Reporting a Vulnerability
If you discover a security vulnerability, please use the repository's **Private Vulnerability Reporting** feature under the Security tab. Do not open a public issue.

## Response Timeline
- **Acknowledgment:** Target 48 hours.
- **Initial Assessment:** Target 7 days.
