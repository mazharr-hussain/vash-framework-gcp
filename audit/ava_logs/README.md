# runtime/ava_logs/

This folder stores all Agent vs Agent (AvA) review logs, one file per round per task.

## Naming convention
`[task_id]_round[n].md`
Example: `0.1_round1.md`

## Contents per log
- Task ID and name
- Round number
- Junior artifact reference
- Senior review comments
- Score (out of 100)
- Decision: APPROVED / MODIFY / FAIL
