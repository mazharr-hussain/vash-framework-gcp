# Checklist: Manual Step Activity

Use this checklist for every activity with TYPE: MANUAL before marking complete.

## Pre-execution
- [ ] method/laws.md has been read
- [ ] Step is clearly understood — no ambiguity
- [ ] Human approval has been obtained if required

## Execution
- [ ] Step performed exactly as described
- [ ] No automation shortcuts bypassed human approval gates
- [ ] Outcome verified against expected result

## Post-execution
- [ ] Result documented in audit/validation/[task_id]_summary.md
- [ ] Status updated to PASS or FAIL in plan/activity_list.md
- [ ] Next activity dependencies checked before proceeding
