# Checklist: Prompt Review

Use this checklist when reviewing or generating prompts for VASH activities.

## Prompt quality
- [ ] Prompt states the activity ID and name clearly
- [ ] Prompt includes relevant context from method/
- [ ] Prompt specifies the output format and path
- [ ] Prompt references the correct checklist
- [ ] Prompt states the AvA threshold score

## Compliance
- [ ] Prompt does not ask for actual software code
- [ ] Prompt respects LAW 1 (Vanilla First)
- [ ] Prompt enforces LAW 2 (Agent Over Human)
- [ ] Prompt requires LAW 3 search documentation

## Saving
- [ ] Prompt saved to audit/prompts/[task_id]_prompt.md before use
- [ ] Prompt version noted if revised between AvA rounds
