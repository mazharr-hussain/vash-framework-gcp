# runtime/triggers/

This folder is watched by GitHub Actions.
When P1 pushes a trigger file here, ava.yml fires automatically.

## Naming convention
[task_id]_trigger.md
Example: 3-1_trigger.md

## Contents per trigger file
TASK_ID: [e.g. 3.1]
ACTIVITY: [activity name]
REQUESTED_BY: P1
TIMESTAMP: [ISO-8601]
